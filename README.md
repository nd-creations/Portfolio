# Naveen ND - Portfolio Website

A modern, responsive portfolio website with smooth animations, interactive elements, and a fun Flappy Bird game!

## 📁 File Structure

```
portfolio/
│
├── index.html          # Main HTML structure
├── style.css           # All styling and animations
├── script.js           # JavaScript functionality
├── profile.png         # Your profile image (add your own)
└── README.md           # This file
```

## 🚀 Quick Start

1. **Download all files** and place them in the same folder
2. **Add your profile image** named `profile.png` to the folder
3. **Open `index.html`** in your web browser

That's it! Your portfolio is ready to use.

## ✨ Features

### 🎨 Design Features
- Modern gradient background
- Smooth fade-in animations
- Rotating green border around profile image
- Responsive design for all devices
- Mobile-friendly navigation menu

### 💼 Portfolio Sections
- **Home** - Introduction with typing effect
- **About** - Brief description of your skills
- **Projects** - Showcase of your work
- **Skills** - List of technologies you know
- **Contact** - Contact information with social links

### 🎮 Interactive Elements
- **Flappy Bird Game** - Mobile and desktop compatible
- **Social Links Configurator** - Click the settings gear to add your social profiles
- **Smooth Scrolling** - Navigate smoothly between sections
- **Typing Animation** - Dynamic text cycling in the hero section

## 🎮 Game Controls

### Flappy Bird Game
- **Desktop**: Click anywhere on the game canvas
- **Mobile**: Tap anywhere on the screen
- **Goal**: Navigate through green pipes without hitting them
- Your best score is automatically saved!

## ⚙️ Customization

### Update Your Information

**In `index.html`:**
- Replace "Naveen ND" with your name
- Update the description text
- Change project links and descriptions
- Update contact information
- Add your profile image

**In `script.js`:**
- Modify the typing text array to show different titles:
  ```javascript
  const texts = ["Your Title 1", "Your Title 2", "Your Title 3"];
  ```

**In `style.css`:**
- Change color scheme by modifying the `#2afc85` (green) color
- Adjust animation speeds and timings
- Modify spacing and sizing

### Add Your Social Links

1. Click the **settings gear** button (bottom right)
2. Enter your usernames for:
   - GitHub
   - LinkedIn
   - Twitter
   - Instagram
3. Click **Save Links**
4. Your links are now active!
